There are a lot of media out there, and a lot of steaming services to watch your favorite TV show / movie. Most recommendation algorithms for finding content will only recommend content in whatever language you set as your native language. The problem? As a language learner, I want to find content that I can use to develop my skills in a language, with context of how difficult the content is, and discover what service I can use to access it. This service will also be good for users to connect with friends learning the same language, and recommend content to them.

Criteria:
* User should be able to make a profile with the following data
  * Username
  * Target Languages
  * Preferred Genres
* User should have a discovery page where they can select the language they are looking for, and optionally whether they want TV or movies, and get varied recommendations based on profile settings
* User should be able to add friends
* User should be able to share content with friends
* User should be able to review content

Constraints:
* Upkeep costs must be less than $20/mo
